# GEO 信源配图（Answer Card）

## 适用场景
- GEO 六段式内容（问题前置→直接答案→参数表格→清单建议→实体锚点→信源引用）的配图
- 知乎回答、公众号长文、垂媒稿件、百科词条的首图与对比图

## 方法
1. 图表优先：参数对比用横向条形/表格版式，避免纯装饰大图；
2. 每张图只讲一个结论（一张对比图 = 一个维度）；
3. 实体锚点（品牌名/型号/参数）与品牌实体卡逐字一致，字体统一、数字对齐；
4. 引用来源以文字层标注（来源 + 时间），不伪造数据图；
5. 一次生成「首图 + 对比图 + 清单图」三张套装，供同一篇文章使用。

## 输出契约
- 3 张套装（首图/对比图/清单图）+ recipe + 回执；
- 每张图的数字与实体卡一致；外发前走 G-GEO2 事实校验与 G-GEO1 必审。

## 边界
- 不做「排名第一/碾压」类对比图；不引用未核实第三方数据（G-VIS2）；
- 图片不替代正文的事实核查。
