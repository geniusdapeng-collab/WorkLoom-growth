# 多规格变体（Variant Forge）

## 适用场景
- 同一主视觉要覆盖多平台（小红书 3:4 / 抖音 9:16 / 朋友圈 1:1 / 公众号 2.35:1）
- 投流素材需要「钩子 × 规格」矩阵做 A/B 测试

## 方法
1. 定义变量矩阵：`hooks[]`（疑问/冲突/利益）× `specs[]`（平台规格）；
2. 用同一 recipe 模板批量渲染，保持字体、色板、品牌锚点一致，仅换文案与画布；
3. 命名规范：`题材_钩子_版本_规格`，写入一客一档时记录来源成片/素材链；
4. 输出变体清单 JSON（变体 id、规格、钩子、sha256），供投放侧绑定；
5. 淘汰复用：连续低效的钩子进「低效钩子库」，不重复生产。

## 输出契约
- N×M 变体成品 + 变体清单 + 回执；同一变体可复现（recipe + 素材哈希）。

## 边界
- 变体只改表达不改事实；价格/权益变体必须来自已确认口径；
- 单租户日渲染受 G-VIS3 配额约束，超限转人审。
