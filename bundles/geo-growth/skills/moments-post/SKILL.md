# 朋友圈发图（Moments Post）

## 适用场景
- 私域运营的朋友圈单图/九宫格：上新预告、活动通知、客户案例、节气问候、直播预热
- 需要「同一眼识别 + 不显广告 + 带私域 CTA（加微/进群/预约）」的版式

## 方法
1. 套图组版：3/6/9 张使用同一底色、同一字体、同一角标（第 N/总数）；
2. 单图信息 ≤ 3 块：主标题、利益点、行动指令（如「评论 1 领选型表」）；
3. 九宫格视觉节奏：首图主标题、第二到八图分点、末图 CTA + 二维码留白区；
4. 二维码/联系方式由客户提供素材，作为图片层叠加，不生成假二维码；
5. 出图后 `visualread.verify` 校验每张尺寸一致（宫格对齐）。

## 输出契约
- 成套图片（3/6/9）+ 每张 sha256 + 统一 recipe 版本；
- 私域 CTA 文案过合规检查（G-VIS2），价格/名额以客户确认为准。

## 边界
- 不做诱导分享、不承诺收益；客户案例需授权（G-VIS1）；
- 群发动作不在此技能内（走发布/私域岗位与人审）。
