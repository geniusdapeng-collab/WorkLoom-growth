# 设计质量闭环（获客素材）

> 背景：第一版海报是"工程审美"——程序化矢量当素材、无艺术指导、无评审直接交付。
> 视觉模型（DeepSeek Flash）评审给出 overall 5.5/10；按本流程迭代到 7.4/10（多样本中位数）后交付。
> 结论：**质量问题不是单一环节，而是缺流程**：缺素材策略、缺艺术指导、缺评审、缺收敛判据。

## 六个阶段（每阶段有产物与门）

| 阶段 | 技能 | 产物 | 门 |
|---|---|---|---|
| ① 需求分析 | `design-brief` | brief.json（受众/渠道/目标/成功标准/必须/禁用/规格/素材来源） | 人确认 |
| ② 概念构思 | `art-direction` | 2-3 个方向 + 参考图（正版图库/客户素材） | 选 1 个方向 |
| ③ 艺术指导 | `art-direction` | 色板/字体/网格/素材清单（含授权） | 规范冻结 |
| ④ 设计执行 | `product-poster` 等场景技能 + `compositor-designer` | recipe → `.comp` → PNG + 回执 | 尺寸/哈希校验 |
| ⑤ 视觉评审 | `design-critique` | `visualread.critique`（samples≥2，中位数）+ top3 修改 | overall≥8 或连续两轮提升<0.5 且无红线 |
| ⑥ 终审交付 | `brand-guard` | 评审记录 + QC 报告 + 一客一档归档 | 人工终审；外发走 G9/G-GEO1 |

## 素材优先级（决定上限的不是排版，是素材）

1. **客户实拍/视频抽帧**（首选，授权明确、可信度最高）；
2. **正版图库**（Unsplash/Pexels；`visualwrite.fetch_stock` 落库 + license sidecar）；
3. **AI 生图**（`visualwrite.generate`，需配置模型/key；生成图必须带 AI 标识）；
4. 程序化矢量/纯色 **只用于版式元素与数据图**，不能冒充产品摄影。

## 评审的工程细节（实测经验）

- **单次模型评分有方差**：同一张图两轮评分可能相差 ±1 分（本机实测 v8：6.5 与 7.5）；
  → 规则：`samples ≥ 2` 取中位数；重要物料 3 样本。
- **模型偏好会与品牌策略冲突**：它可能既嫌"C 太高促销"又嫌"描边按钮不像按钮"；
  → 规则：只采信"可执行且不违背 brief"的建议，冲突时人工裁决并记录理由。
- **评审不能替代人工**：品牌事实、授权、平台规范由 `brand-guard` + 人终审。
- **每轮只改 top3**，并保留每轮评审 JSON——这是下一次的偏好数据。

## 反模式（本次复盘）

1. 用程序化矢量当"产品/场景素材" → 材质与体积感缺失，被评审打 4/10；
2. 没有艺术指导直接排版 → 字体/色彩/构图靠默认值，像通用模板；
3. 文字压在主体高光上 → 缩略图不可读；
4. 促销色滥用 → 与"温暖克制"的 brief 冲突；
5. 单轮出图直接交付 → 没有收敛判据，质量靠运气。

## 生产节拍

- 单张物料：brief → 方向 → 执行 → 评审 → 修改（1-3 轮）→ 终审；
- 批量变体：方向与规范冻结后，用 `asset-variant-forge` 批量出，抽检 30%（首月全检）；
- 周报：`visual-kpi.mts` 统计产量、回执率、评审中位数、驳回原因，进 ops-rhythm。
