# Growth 运行与客户交付整改

任务 T-2026-1002-0901；CNB Issue #316。本次修复 2026-10-02 审计发现的 16 个问题，并处理与交付直接相关的定妆照驳回、交付摘要校验、织伴遮挡、首日引导遮罩和发布器引用匹配问题。

## 用户现在会遇到的行为

没有权限的动作在调用工具前被拒绝。同一任务被同时续跑时，只能有一个执行者。人修改金额、日期等参数后采纳，实际执行使用新参数；参数未补齐时继续等待补齐。系统明确禁止的动作仍然禁止，人工审批不能覆盖红线。

任务重放会复用已保存的计划与审核标记。已经取消或完成的任务不能通过普通运行恢复。写工具超时、抛错，或者只有开始记录而没有最终回执时，任务失败并提示未核实；操作人员先核对外部实际结果，再决定恢复方式。读工具的可重试失败保留重试语义。排队十条任务不会堵住空闲执行槽。两个工作区使用同一驳回理由分别记录自己的组织记忆。

生产 Web 的匿名访客无法使用演示入口取得店主身份。桌面程序通过本机初始化的高熵凭据登录安装时预配的工作区；凭据由隔离 preload 提供，页面不能选择任意工作区或成员。服务端验证 JWT 的算法、签发方、签发时间和过期时间，生产密钥不符合要求时拒绝签发和验证。

影片工位现在实际启动工作子进程，子进程通过父进程调用组件。父进程验证调用所属任务、来源摘要、选项与预算/审核约束；结束前验证每个请求阶段的实际调用或缓存记录，以及结果文件和交付摘要。缺少阶段、缺少产物或超过硬截止不能标为完成。子进程只接收允许的环境字段；这是进程边界约束，未宣称操作系统安全沙箱。

独立 M6 在父通道发现并复现方法、阶段与镜号之间的绑定缺口。服务现在在预占预算前检查方法所属阶段、完整步骤键、冻结镜头及 `only` 选择范围；评审另核对项目、镜号、阶段别名与素材来源。未通过这些检查的请求没有组件预占或供应商调用。

定妆照人审可用 `portrait-agent reject` 记录具名否决，必须提供审查人和理由。后续机器意见保留为证据，不替代人类决定。影片 CLI 的创作意见沿用既定 advisory 口径；事实、权限和产物存在性仍是执行条件。

客户载荷包含所需模块、内置运行环境和精确依赖。工作区模块使用实体入口保持路径和单例一致。首次启动自行准备数据库并使用随机凭据和 SCRAM。渲染冒烟会退出欢迎页与首日遮罩，再验证首页、数字人和场景像素。

Electron 装配和 Windows 应急装配现在在遍历源码前排除开发 `node_modules`，避免先解引用复制整个 pnpm 依赖树再删除而耗尽磁盘。源码路径和链接仍受仓库边界约束，实际构建产物保留；运行所需依赖继续按精确锁单独安装。Mac 应急装配原有 rsync 排除规则保持。

实际新包复验又发现欢迎仪式与首日引导之间的异步空帧：一次查询未看到引导，下一次 React 提交才出现遮罩。渲染冒烟现在在原有 10 秒截止内反复观察；有首日引导入口时必须看到引导、点击真实退出按钮，并持续确认无遮挡。没有退出按钮、退出无效、renderer 执行失败均不能通过。独立补验又发现 renderer 永不返回时仅检查循环时间不够，因此每次观察也受剩余截止时间约束，退出时清理定时器。新增测试覆盖延迟出现、一直不出现、关闭无效、无引导内容包、执行异常和永不返回；原实际失败记录保留。

真机诊断还捕获欢迎页退出后插件迟到导致的 `appendChild(null)`。数字人现在在插件、模型和表情三个异步边界重新检查组件是否已卸载；尚未加入舞台的迟到模型主动销毁，卸载后的回调不能重新安装动作或时钟。四项组件回归先复现三项失败，再验证修复后四项通过。渲染冒烟的 WebGL 能力检测只执行一次，并按 Khronos `WEBGL_lose_context` 规范释放临时上下文，不在每轮页面观察中累积 GPU 资源。原欢迎页 60 秒截止和其他验收阈值保持。

独立补验用实际 React hook 和 PostgreSQL 复现了欢迎旅程的两条竞态。页面现在只接受当前请求的响应，用户选择完成或稍后继续后，仍在运行的阶段计时器不能再发送旧进度；保存失败保留原事实并显示重试提示。数据库保存完成状态后，普通进度、暂停和重复完成请求均不能回退状态、重写完成时间或追加虚假事件，只有显式重播能开始下一次旅程。首日引导在同一次页面挂载中只自动打开一次，用户关闭后的 ready 波动不会再次打开；手动继续仍可用。

场景截图在等待动画稳定后、截取图像前和截取图像后分别重新查询就绪状态、遮罩和人物数量，避免拿数秒前的无遮挡结果给实际被遮住的截图放行。对照回归保留原函数在引导重新出现时误放行的失败记录。安装器也检查同版本目录中的运行时、Node、数据库工具和客户端入口是否实际存在；只剩版本标记的安装不能跳过装配。缺失缓存重装发生故障时，原数据库、配置和版本记录保留。

超过 15 人的欢迎团队改用可滚动的岗位网格，保留每一位员工的形象与完整岗位名。文字可以换行，桌面和窄屏按可用宽度排列；列表可用键盘聚焦和滚动。小团队继续使用原队形。新源码、实际安装包和屏幕验收记录分别保留，源码回归通过不替代新安装包的冷启动验收。

独立检查实际安全模式截图后，又复现 2D 职场 18 人名牌重叠和误选档案。分配器现在按实际字体的文字宽度和字形左右边界，为人物、状态提示和名牌共同留出空间；没有工位或共享工位的员工也有各自位置。每个人首帧即显示在自己的站位，名牌在人物与动画之后绘制，长岗位名完整换行。视口容纳不下时只扩大职场自身的可滚动画布，保留文字大小和所有员工，页面宽度不随之增加。整张名牌响应点击，有任务时进入对应任务，没有任务时进入员工档案；悬停能看到完整任务标题。停用员工不计为已绘制人物，排队任务显示“排队中”。动作与粒子按实际时间推进，场景不能创建或尺寸无效时显示明确错误。文字测量依据 [HTML Canvas TextMetrics](https://html.spec.whatwg.org/multipage/canvas.html#textmetrics)，不是按字符数猜测实际像素。

65 人长岗位的附加检查发现，扩大后的画布起点可能没有员工。职场首次扩大时现在定位到团队中间的一张实际名牌，打开页面即能看到员工；用户滚轮、滚动条或键盘定位后，后续数据刷新和尺寸变化保留用户的滚动位置。

真实生产样式下的首帧补验继续发现，在系统偏好减少动效时，共享样式将所有元素的过渡时长设为 0.01ms，默认的 `transition-property: all` 仍会让尺寸更新延迟到下一帧。原生追踪中首次滚动期望 653/362.5，但实际为 0/0，内容下一帧才从 358×380 扩大到 1590×1686；单独强制读取布局也不能消除该过渡。职场几何容器、画布及投影名牌现在显式使用 `transition-property: none`，尺寸与投影位置即时更新，再执行定位；不修改共享样式或原验收截止。等价 DOM 与实际 CSS 的原生诊断显示首次滚动达到 653/363，真正的产品首帧与用户滚动仍由独立浏览器复验。过渡属性和中间计算值的定义见 [W3C CSS Transitions](https://www.w3.org/TR/css-transitions-1/#transition-property-property)。

完整生产 CSS 的补测还发现，全局内容安全规则会把直接放在视口里的 Canvas 压回父容器宽度：窄屏实测显示宽 358 像素、绘制宽 756 像素，点击仍按未压缩坐标判断。现在把画布放在布局尺寸相同的内容容器内，再由外层独立滚动；保留共享内容安全规则，文字保持测量字号，实际显示位置与点击坐标一致。早先未加载完整 CSS 的独立夹具通过结果保留为有限证据，最终检查必须加载真实构建 CSS。该 CSS 坐标复测的原始 outside 列表只表示观察器坐标基准不一致，不据此声称实际画面有相同数量的人物出屏。

3D 职场改为给全部活动员工分配独立网格位置，包括无工位和共享工位的员工。HTML 名牌保持固定字号、长岗位名完整换行；每帧按实际 DOM 大小、相机投影和人物位置调整名牌，连接线标出对应员工。优先避让人物和指挥台名牌；相机非常靠近时，先保证所有名牌之间与指挥台不重叠，此时不能保证所有人物本体仍有独立点击空间，员工和任务仍能从名牌进入。名牌放不下时扩大自身可滚动区域，达到尺寸上限显示错误。员工离场时释放位置、注视注册和定时器。

GEO 留痕套件按服务端现有完整 5xx 遥测契约识别系统错误事件。这类事件没有模型调用或供应商动作，不伪造对应回执。豁免同时绑定系统身份、错误动作、对象与错误引用、租户、工作区和通道；仅使用系统名字、行业写动作或带外部工具字段的反例仍不能豁免。既有错误事件和哈希链保留。

## 改动归属与选择

本次在 Growth 实验车道中修复现有实现，未回流公共基座或其他行业仓。运行时采用执行前授权凭据和数据库会话锁；选择它是因为权限必须先于外部动作，而且数据库事务不能跨越长时间供应商调用。工具开始与最终结果是两条只增事件，避免事务回滚造成副作用重发。

没有新增数据库迁移。既有事件、审批、计划和记忆结构保存新凭据与作用域。旧组织记忆保留，新的驳回记忆使用包含租户、工作区和理由的身份。客户端 preload 仅提供预配身份所需通道，继续保持隔离上下文。

职场比较了保留画布和 3D 空间并按实际文字分配位置、以及改为 DOM 员工列表两个方案。前者继续使用现有场景、状态动作与点击接口，后者文字布局更容易但会新增另一套职场呈现和交互。此次选择前者，无新依赖；Canvas 分配只在场景、员工内容或尺寸改变时执行，正常动画帧复用结果。3D 名牌在 DOM 尺寸或投影明显改变时重新分配；位置可视范围与原生点击仍以独立浏览器验收和最终客户包记录为准。

## 回滚与运维

按本任务提交整体回滚源码与依赖锁，重建与源码一致的载荷。不要删除或修改已写入的开始、失败、审批和组件事件。已有不明结果的写动作先查外部回执，不能通过清空事件或更改状态强制重放。客户端升级保留客户数据库和日志；使用旧版本程序回滚前先核对旧版是否能读取现有结构。

本次没有开启真实供应商连接器、公开发布客户内容、修改生产秘密或运行客户业务数据。正式发行与实验副本的接收以目标仓验证和实际发布回执为准。
